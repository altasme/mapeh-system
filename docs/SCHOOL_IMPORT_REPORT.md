## How the import behaves (`supabase/seed/school_import.sql`, run after migration 0013)

1. A school already in the database is matched by DepEd ID, otherwise by name within the same district (case and spacing ignored). Matched schools only get the missing DepEd ID and education level filled in. Nothing else about them changes, including their Special Programs / IPED assignment and any linked records.
2. Schools not found are added as active schools with **no program assignment**.
3. Nothing is deleted. Running it twice changes nothing the second time.
4. It ends with read-only listings of conflicts (same DepEd ID but a different name or district) and of schools already in the database that are not in the workbook.

## Special Programs and IPED

The workbook is a general school list. It does not say which schools take part in Special Programs or IPED, so **no school is classified automatically**. After import every new school has no program. Assign programs in **Schools & Accounts** (Admin or Supervisor): Edit a school, tick Special Programs and/or IPED. The program filter there ('No program') lists schools still to be classified. Until a school is classified it cannot be chosen for an SPA/SPS/SPFL or IPED record, but it can be chosen for MAPEH.
